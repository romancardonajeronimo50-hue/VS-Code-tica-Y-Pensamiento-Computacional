Yo desarrollé una calculadora básica en Python que permite realizar operaciones de suma, resta y multiplicación usando solamente números -
del 0 al 9, donde el usuario escribe la operación completa en una línea como 2*7, 7-2 o 1+2, y el programa identifica el signo, separa los -
números, los convierte a enteros y calcula el resultado. Programé validaciones para asegurar que los números estén en el rango permitido y que -
solo se usen los símbolos +, - o *, evitando así errores comunes que surgieron al inicio como fallas por signos incorrectos, datos considerados -
como texto o números fuera del rango, problemas que solucioné agregando condiciones y conversión de datos antes de operar. Para desarrollar este proyecto -
utilicé ChatGPT como apoyo para corregir errores y organizar mejor el código, aunque todas las decisiones y la construcción del programa fueron hechas por mí, usando
la inteligencia artificial únicamente como guía para aprender y mejorar mi lógica de programación. El resultado final es un programa funcional, fácil de usar y -
que cumple con todos los requisitos solicitados, incluyendo el uso responsable de una herramienta de IA y la documentación de los errores encontrados junto con sus soluciones.
